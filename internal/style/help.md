# mdui keys

| Keys | Action | Keys | Action |
|:--|:--|:--|:--|
| `q` `ctrl+c` | quit | `?` | this help |
| `f` | find file | `m` | mouse on / off |
| `tab` `shift+tab` | switch pane | `↑` `↓` `j` `k` | move / scroll |
| `g` `G` | top / bottom | `pgup` `pgdn` | page |
| `←` `h` `→` `l` | collapse/expand | `enter` | open / toggle |
| `ctrl+d` `ctrl+u` | half page | `H` `L` | resize tree |
| `=` | reset split | `r` | raw markdown |
| `.` | hidden files | `T` | table overlay |
| `/` | search document | `n` `N` | next / prev |
| `enter` | footnote link | `double-click` | first child |

`/` searches: `enter` jumps, `n`/`N` cycle with wrap, `esc` clears. Matching
is literal and smart-case; `r` re-applies it to raw markdown.

`f` finds files: type to filter paths, `↑`/`↓` or `ctrl+k`/`ctrl+j` choose,
`enter` opens and reveals, `esc` closes. Matching is case-insensitive and
path-aware.

**Mouse:** click to preview or expand; drag the divider; the wheel scrolls the
pane under the pointer. Table footnotes are clickable; remote URLs ask `y`/`n`.
Hold **shift** for native selection.

`?` or `esc` to close this help.
