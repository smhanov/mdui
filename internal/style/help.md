# mdui keys

| Keys | Action | Keys | Action |
|:--|:--|:--|:--|
| `q` `ctrl+c` | quit | `?` | this help |
| `tab` `shift+tab` | switch pane | `m` | mouse on / off |
| `↑` `↓` `j` `k` | move / scroll | `g` `G` | top / bottom |
| `←` `h` `→` `l` | collapse / expand | `enter` | open / toggle |
| `ctrl+d` `ctrl+u` | half page | `pgup` `pgdn` | page |
| `H` `L` | resize tree | `=` | reset split |
| `r` | raw markdown | `.` | hidden files |
| `T` | full-width table | `enter` | open first visible link |

**Mouse:** click a file to preview it, click a folder to expand or collapse,
double-click a folder to open its first item. Drag the divider to resize.
The wheel scrolls the pane under the pointer. Click a table footnote link
(`[1]`, `[2]`, …) to follow it; remote URLs ask for `y` or `n`
confirmation.
Hold **shift** for the terminal's native selection.

Press `?` or `esc` to close this help.
