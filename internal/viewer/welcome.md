# Welcome to mdui

Pick a markdown file in the tree on the left and it appears here.

| Key | Action |
|:----|:-------|
| `j` / `k`, `↑` / `↓` | scroll one line |
| `PgUp` / `PgDn` | scroll one page |
| `g` / `G` | jump to top / bottom |
| `ctrl+d` / `ctrl+u` | half page |
| `r` | toggle raw markdown |
| `Tab` | switch panes |
| `q` | quit |

Tables are rendered with aligned columns and wrapped cells. Links inside a
table are listed underneath it so they stay readable at narrow widths.

Files larger than 2 MB open with a warning instead of being rendered; press
`r` to read their raw source.
